# Simulación Estocástica

**Maestría en Estadística Aplicada**  
**Facultad de Ciencias Exactas — Universidad Juárez del Estado de Durango (UJED)**

Repositorio académico de materiales, prácticas y notebooks de Python para Google Colab.

## Organización

El repositorio contiene 11 carpetas correspondientes a los módulos del curso:

1. Módulo 1: Fundamentos
2. Módulo 2: Numeros Aleatorios
3. Módulo 3: Variables Aleatorias
4. Módulo 4: Procesos Estocasticos
5. Módulo 5: Monte Carlo
6. Módulo 6: Reduccion Varianza
7. Módulo 7: Sistemas Colas
8. Módulo 8: Cadenas Markov
9. Módulo 9: MCMC
10. Módulo 10: Validacion
11. Módulo 11: Implementacion

## Uso de los notebooks

1. Abrir un archivo `.ipynb` desde GitHub.
2. Seleccionar **Open in Colab** cuando esté disponible o cargar el archivo en [Google Colab](https://colab.research.google.com/).
3. Ejecutar las celdas en orden.

Los ejercicios de simulación emplean una semilla aleatoria de 42 para favorecer la reproducibilidad.

## Contenido inicial

- Módulo 1: experimento determinístico frente a experimento estocástico.
- Módulo 2: generación y evaluación de números pseudoaleatorios.
- Módulo 3: simulación de variables aleatorias normales.
- Módulo 4: trayectorias de un proceso de Poisson.
- Módulo 5: estimación de π por Monte Carlo.

Los módulos 6 a 11 están preparados para incorporar materiales adicionales.
